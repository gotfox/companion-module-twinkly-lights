# companion-module-twinkly-pro

Bitfocus Companion module for [Twinkly Pro](https://twinklypro.com) controllers (PRO, MAX, PLUS, Lightwall) using their OSC interface.

See [HELP.md](./companion/HELP.md) and [LICENSE](./LICENSE).

## Development

```bash
yarn            # install
yarn build      # compile to dist/
yarn dev        # watch mode
yarn test       # build + unit tests (OSC encoding and addressing)
yarn lint
yarn package    # build a distributable .tgz
```

Protocol reference: <https://help.twinklypro.com/guides/osc/>
